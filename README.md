# KiMa — Personal Page

A one-page personal website for a QA engineer, hosted on [GitHub Pages](https://kima30.github.io/).

## Tech Stack

- HTML5
- [Tailwind CSS](https://tailwindcss.com/) (CDN)
- GitHub Pages

## Project Structure

| File | Description |
|------|----------|
| `index.html` | Main page |
| `icons8.ico` | Favicon |
| `README.md` | Project documentation |

## Local Development

Open `index.html` in a browser or use a simple HTTP server:

```bash
npx serve .
```

The site will be available at `http://localhost:3000`.

## Deployment

Push changes to the `main` branch of the `KiMa30.github.io` repository. GitHub Pages will publish the site automatically.

## Design

The interface is inspired by desktop banking application layouts:

- light theme with a `gray-50` background
- purple accents
- cards with a large border radius
- sidebar with quick links
- responsive layout for mobile devices
